Motion: connecting a wallet and approving a transaction

Previews only. With Solana Mobile Wallet Adapter the wallet app (Phantom, Solflare, Seed Vault) draws its own approval screen; Vanna owns the moment before it, the wait while you are in the wallet, and the result. Every animation below follows a real event (wallet answered, Solana confirmed); nothing is a timed fake. Durations and curves are Material 3's. Each phone loops; the buttons jump to other outcomes. The wallet here is shown as "Phantom" with a neutral icon; the app would show the real installed wallet's name and icon.

1 · Connect your wallet: three designs

All three cut the copy to one title, one line and one button, and name the wallet ("Open Phantom") instead of explaining Mobile Wallet Adapter. Returning users never see any of this: the saved authorisation is reused.

2 · Approving a transaction

No review step and no separate status screen: the order screen already shows the trade, so the "Open 3x Long" button itself carries the whole transaction. Tap → "Opening Phantom" → the wallet's own sheet → back on the same screen the button opens into a small status card: Sent → Processed → Confirmed (real Solana steps, usually under 2s, not a progress bar) → result. No confetti: a leveraged trade should feel settled, not like a win. Cancelling in the wallet is not an error, so it is neutral, not red.
